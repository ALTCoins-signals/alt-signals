The Chrome extension scans up to 100 USDT perpetual futures coins and ranks the TOP-30 most active by an activity score from 0 to 100. It shows 5-minute and 15-minute price change, open interest change, volume spike, funding rate, taker buy/sell pressure and ATR, and refreshes every 60 seconds while the popup is open.
